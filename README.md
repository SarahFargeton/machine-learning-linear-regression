# Linear Regression Learning Project

## Overview

This project was completed as part of an introductory Artificial Intelligence course in Biotechnology Engineering at ESTBB.

The objective was not to build a highly accurate predictive model, but to understand the workflow of a machine learning project and explore the role of the main Python libraries used in data analysis and linear regression.

## Learning Objectives

- Import and explore a real-world dataset
- Perform descriptive data analysis
- Identify and handle missing values
- Split data into training and testing sets
- Build a linear regression model using Scikit-learn
- Evaluate model performance using R² and RMSE metrics
- Understand the purpose of each step and command involved in the workflow

## Dataset

The project uses the Wine Quality dataset containing physicochemical characteristics of red wines and their associated quality scores.

## Tools and Libraries

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Key Concepts Practiced

- Supervised machine learning
- Data preprocessing
- Feature-target separation
- Train/test split
- Linear regression
- Model evaluation
- Interpretation of performance metrics
